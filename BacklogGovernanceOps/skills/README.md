# BacklogGovernanceOps Skills Placeholder

This folder is intentionally a placeholder.

`BacklogGovernanceOps` does not yet require workflow-local skills because the
current backlog-governance workflow is still operating primarily as a
document-driven, folder-based, Product Owner governed process with one
implemented deterministic script for intake triage.

Create skills in this folder when one or more governance tasks need a stable,
reusable Codex instruction surface, for example:

- intake triage execution and verification
- review-state admission handling
- approval-state publication-readiness checks
- card-activity drafting or normalization
- duplicate exception handling
- future API intake behavior once Phase 2 is built

Until those tasks need dedicated Codex workflow packaging, use the existing
workspace guidance instead:

- `README.md`
- `AGENTS.md`
- `docs/BACKLOG_GOVERNANCE_USAGE.md`
- `docs/finopsai_backlog_governance_workflow.md`
