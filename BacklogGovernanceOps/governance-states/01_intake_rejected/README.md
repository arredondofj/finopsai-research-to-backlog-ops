# Rejected Intake Artifacts

This folder stores intake artifacts that were explicitly rejected by the Product
Owner during Phase 1 governance intake.

## Operating rule

- Record the rejection first in the matching `governance-records/card-activity/`
  file.
- Then move the rejected artifact here.
- Do not leave rejected artifacts in `../01_intake/` once the rejection is
  durably recorded.
- These artifacts are retained for reopening, auditability, and source-trace
  review. They are not active intake items.
